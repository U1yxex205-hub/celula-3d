# Célula 3D de estudio

Modelo 3D interactivo de una célula animal con fichas por organelo, plano de corte, vista separada, procesos animados y modo examen.

Abre `index.html` desde GitHub Pages (no funciona con doble clic en el archivo, porque el navegador bloquea la carga del modelo desde el disco).

## Créditos

Basado en "Celula" de k10tra (https://sketchfab.com/3d-models/celula-23c9bccc33cb4d2f8ec3a0903262bf29), licencia CC-BY-4.0. Las piezas agregadas (citoesqueleto, mitocondria en corte, vesículas, autofagosoma, etc.) y el visor son trabajo derivado.
